# My Personal AI Usage Rules

## Rule 1 - What I will never paste

I will never paste real credentials, API keys, .env values, or real user/customer data into any AI tool — even test data must be fabricated. I will also strip or generalize local file paths before pasting stack traces, since I've done this before without noticing.

## Rule 2 - What I will always verify before accepting

Before accepting any AI-generated finding, code, or config, I will check it against the actual file and line it references — not just the AI's description of it. If I can't independently explain why something is true, I treat it as unverified.

## Rule 3 - How I will record AI contributions

I will log what AI generated or suggested, grade it (e.g., Valid/Noise/Wrong), and note why — in docs/ files like final-ai-review.md — rather than relying on memory or an unlogged chat history."
